\textcolor{blue}{For the revision, we added real-data adaptive-baseline experiments in addition to the original LIBSVM comparison.}
The added experiments use real bundled datasets (diabetes, breast-cancer, and digits) so that the Docker workflow can run even if external dataset mirrors are unavailable, while preserving the original LIBSVM download path.
The results are summarized in \Cref{tab:review_realdata} for $T=100$ review runs on a cycle graph.
They show that tuned adaptive decentralized baselines can be competitive or better on some datasets and horizons.
Therefore, the empirical conclusion is not that \algname{} uniformly dominates tuned adaptive methods; rather, \algname{} provides learning-rate-free decentralized coin-betting updates with explicit communication accounting and regret guarantees in the convex online-learning setting.
